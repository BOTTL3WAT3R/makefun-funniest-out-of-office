A single line of an out-of-office auto-reply, written to be the funniest one in the inbox: the sender is away until the 30th, and the reply itself was scheduled back in March by a version of him who still assumed the 30th meant this month. A small Python program writes the line to /output/entry.txt.

## Run it

```sh
python3 main.py
```
